# Progressive reading

Read the entry, one task index, and one feature index. Use codebase-memory
search to locate exact symbols, then read only the relevant snippets. Expand to
a second feature index or risks page only for cross-domain impact.

Stop gathering when you can identify the entry point, data flow, files to
change, invariants, and verification method. Re-index before trusting graph
results that conflict with current source.
