# Changelog

## Unreleased

### Added

- Initial Scribeva Editor package with ESM, CJS, CSS, types, and MIT license.
- Word-inspired Ribbon UI, document canvas, status bar, themes, and locales.
- Document model, snapshot history, commands, Selection/Range browser engine,
  IME handling, and clipboard normalization.
- HTML allowlist sanitizer and deterministic HTML/JSON conversion.
- Unit, integration, E2E specifications, demo playground, living
  documentation, and codebase-memory workflow.
- Open-font-only Noto stacks with OFL references and consumer-hosted font
  guidance.
- Validation-free dialog cancellation, grouped keyboard undo/redo, emoji,
  sanitized preview, and Blob image insertion with URL lifecycle cleanup.
- Japanese product/editor localization alongside Traditional Chinese and
  English.
- Complete table row/column/header/merge/split/delete/vertical-align commands.
- Three-language official site and directly usable playground with a GitHub
  Pages deployment workflow.
- CSP deployment guidance and enforced unit coverage thresholds.
- GitHub Actions quality automation, three-engine browser verification, visual
  regression coverage, and packed-package ESM/CJS smoke testing.
- Forest-green editorial website redesign with reduced-motion-aware GSAP
  animation, localized example documents, full SEO metadata, and branded Open
  Graph artwork.
- Direct `file://` website execution through committed classic JS/CSS assets,
  with no TypeScript or ES-module CORS requirement.
- Table outline/grid color, width, style, active-cell fill, and formatting reset.
- Sanitized HTML source editing tab with line numbers, caret position, Tab
  indentation, wrapping, apply/revert controls, automatic safe commit on tab
  exit, and Ctrl/Command+S.
- Table top, bottom, left, right, paired outer-edge, all-edge, and no-border
  presets using the selected border color, width, and style.
- Expanded website motion with staged hero construction, document parallax,
  page progress, editor reveal, and staggered content transitions.
- Validated free-entry font sizes and line heights, expanded/custom emoji,
  mathematical-symbol insertion, and persistent one- through four-column
  document layouts with HTML/JSON round-trip coverage.
- Synchronized preset-plus-custom controls for font size, line height, and
  table border width with inputs shown only in custom mode; grouped directional
  SVG table row/column actions with accessible labels; and layout-aware document
  zoom with step controls and reset.
- Opt-in sticky editor toolbar for long pages, print-aware page breaks,
  icon-only table structure actions, sortable reader tables, and drag-to-reorder
  table columns with sanitized metadata and undoable authoring commands.
- Configurable sticky-toolbar top and bottom offsets, default-visible page-break
  markers, editor-only isolated printing, and a previewable Templates tab with
  four localized, undoable starter documents.
- Separate, opener-isolated print-preview tabs that never alter host-page print
  state; a three-section View ribbon; and four additional creative templates
  for brand, launch, case-study, and workshop workflows.
- A dedicated campaign-concept template with advertising-brief structure
  (insight, headline, key visual, and CTA), plus theme cards and a document-view
  hint in the View panel.
